# All imported documents restart at V1 on a single Baseline Date

Every Controlled Document imported into the Document Register is issued as V1 on one shared Baseline Date, regardless of its prior version. Each keeps its Legacy ID(s) (prior Document ID + Version, e.g. `HR_POL008_V3`, `POL_005_V1`) so Records that cite old versions — e.g. signed Policy Transmittals — remain traceable, and superseded source files are archived separately from the new V1s.

We chose this over continuing version numbers because the existing versions were unreliable (the old register and the files disagree, e.g. Core Values V1 vs V3) and many Document IDs change anyway under the IMS numbering scheme. ISO 9001 §7.5.3 requires controlled, traceable change, not continuous numbering, so the reset must itself be documented: recorded in the next IMS Manual revision (§4.2.1) and in Management Review minutes.
